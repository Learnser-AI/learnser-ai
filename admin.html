Manage Exam Shifts

Define custom examination shifts (e.g., "Shift 1 / Morning", "Shift 2 / Evening", "27 Jan S1"). These will appear in the exam shifts dropdown when creating questions.

Supabase Table Setup Required

The 'shifts' table was not found or is inaccessible in your Supabase database. Using local fallback shifts list. To enable database-backed shift management, run this SQL in your Supabase SQL Editor: 

CREATE TABLE public.shifts (
    id bigint generated by default as identity primary key,
    name text not null unique,
    year text not null default '2026',
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Enable Row Level Security (RLS)
ALTER TABLE public.shifts ENABLE ROW LEVEL SECURITY;

-- Create policies for public access (Adjust in production)
CREATE POLICY "Allow read access for all" ON public.shifts FOR SELECT USING (true);
CREATE POLICY "Allow write access for all" ON public.shifts FOR ALL USING (true) WITH CHECK (true);

Review Reported Errors

Moderate and correct errors reported by users. Clicking "Edit Question" loads the question details directly into the "Questions DB" tab form to make fixes, and "Mark Solved" resolves the report.

Supabase Table Setup Required

The 'reported_errors' table was not found or is inaccessible in your Supabase database. Please run this SQL in your Supabase SQL Editor to create it: 

CREATE TABLE public.reported_errors (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    question_id UUID REFERENCES public.questions(id) ON DELETE CASCADE,
    user_id UUID REFERENCES public.profiles(id) ON DELETE SET NULL,
    status TEXT NOT NULL DEFAULT 'unseen',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);
ALTER TABLE public.reported_errors ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public Read/Write Access" ON public.reported_errors FOR ALL USING (true) WITH CHECK (true);
